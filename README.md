## 📖 О проекте и задумка

**FETCHY!** — это эксперимент в мире анонимных коммуникаций. Мы устали от мессенджеров, которые требуют номер телефона, собирают метаданные и читают переписку. 

**Задумка:** Создать приложение, где каждый пользователь может развернуть свой собственный «сервер» (базу данных Firebase) и пригласить туда друзей, не регистрируясь нигде. Все сообщения шифруются на устройстве отправителя (AES-GCM + PBKDF2) и расшифровываются только на устройстве получателя. Даже Firebase видит только «мусор» из символов.

Приложение полностью работает на клиенте. Скачал файл, открыл в браузере — и ты в сети.

> [!CAUTION]
> **⚠️ Дисклеймер о нейросетях**
> При разработке интерфейса, архитектуры и кода этого приложения активно использовались нейросети. Код может содержать неоптимальные решения или скрытые баги. Используйте на свой страх и риск.

> [!WARNING]
> **⚠️ О возможных багах**

- 🔒 **Сквозное шифрование** — пароль в базу не пишется, из него выводится ключ.
- 🛡️ **Анонимная авторизация** — доступ к базе только через приложение (Firebase Auth).
- 🎨 **12 тем и 2 дизайна** (NeoBrutalism / Minimalistic) + светлая/тёмная схема.
- 🅰️ **10 шрифтов**, настройка размера и курсива.
- 🖼️ **Отправка фото** со сжатием и шифрованием.
- 📁 **Отправка файлов и видео** через Google Drive.
- 🗑️ **Групповое выделение** и удаление, очистка чата (только владелец).
- 🎵 **Звуки интерфейса**, синтез в браузере (без внешних файлов).
- 📱 **Адаптивная вёрстка** + ручной resize панелей на ПК.
- 🥚 **Пасхалки** (попробуй ввести `burger` в секретном меню).

## 🚀 Быстрый старт

1. Скачай HTML файл из этого репозитория.
2. Открой его в любом современном браузере (Chrome, Firefox, Safari).
3. Создай чат, следуя инструкции ниже.

---

## 🛠 Инструкция по настройке Firebase

Чтобы чат заработал, тебе нужна своя база данных. Это бесплатно.

### Шаг 1. Создание проекта
1. Зайди в Firebase Console.
2. Нажми «Add project» (Добавить проект), введи название и создай его.

### Шаг 2. Включение анонимной авторизации
1. В левом меню выбери **Authentication**.
2. Нажми **Get Started**.
3. Перейди во вкладку **Sign-in method**.
4. Найди **Anonymous**, переключи тумблер в положение **Enable** и сохрани.

### Шаг 3. Создание Realtime Database
1. В левом меню выбери **Realtime Database**.
2. Нажми **Create Database**.
3. Выбери локацию, нажми **Next**.
4. Выбери **Start in test mode** и нажми **Enable**.

### Шаг 4. Настройка правил (Security Rules)
> [!CAUTION]
> Это критически важный шаг. Если его пропустить, любой человек по ссылке сможет читать ваши сообщения.

1. В Realtime Database перейди на вкладку **Rules**.
2. Удали всё, что там написано, и вставь следующий код:

{"rules": { "fetchok_chats": { "$chatId": { ".read": "auth != null", ".write": "auth != null" } } }}

3. Нажми кнопку **Publish**.

### Шаг 5. Получение ключей
1. Нажми на **шестерёнку** ⚙️ рядом с «Project Overview» -> **Project settings**.
2. Прокрути вниз до раздела **Your apps**.
3. Если веб-приложения нет, нажми на иконку `</>`, введи название и зарегистрируй.
4. Скопируй из блока `const firebaseConfig` две строки:
   - **`apiKey`** (начинается с `AIzaSy...`)
   - **`databaseURL`** (начинается с `https://...firebaseio.com`)

### Шаг 6. Создание чата
1. В приложении нажми «+».
2. Введи название, пароль (запомни его!), **API Key** и **Database URL**.
3. Нажми «Создать». Приложение выдаст 10-значный код чата.

Передай другу **код, пароль, API Key и Database URL** — и он сможет к тебе подключиться.

## 🧠 Технологии

- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3.
- **База данных:** Firebase Realtime Database.
- **Авторизация:** Firebase Auth (Anonymous).
- **Шифрование:** Web Crypto API (AES-GCM, PBKDF2).

---

## ⚠️ Безопасность

Помни, что приложение использует **локальное шифрование**. Это значит:
- Никто (даже Google) не прочитает твои сообщения без пароля.
- Если ты забудешь пароль от чата — переписку **невозможно** восстановить.
